# UNIVEN Construction Management System

A starter web application for managing and displaying construction projects around the University of Venda campus.

## Technology
- HTML, CSS, JavaScript
- Node.js + Express backend
- JSON file storage (easy to run without installing MySQL)
- Leaflet + OpenStreetMap for the interactive map

## Run
1. Install Node.js.
2. Open a terminal in `backend`.
3. Run:
   `npm install`
4. Run:
   `npm start`
5. Open `http://localhost:3000`
